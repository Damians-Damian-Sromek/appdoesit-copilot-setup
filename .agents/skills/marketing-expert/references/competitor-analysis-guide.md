# Competitor Analysis Guide

## Analysis Levels

### App-Level Analysis

Focus on direct competitors for a specific app type.

**Search queries:**
```
"free online [app-type]"
"[app-type] calculator" OR "[app-type] converter" OR "[app-type] tool"
"[app-type]" site:producthunt.com
"[app-type]" site:alternativeto.net
best free [app-type] tools 2024
```

**Example for Calculator app:**
```
"free online calculator"
"scientific calculator online"
calculator site:producthunt.com
```

### Portal-Level Analysis

Focus on competing multi-tool portals.

**Search queries:**
```
"free online tools" collection
"web tools" portal
sites like 10015.io
sites like smalldev.tools
"online utilities" free
"developer tools" collection
```

**Known competitors:**
- 10015.io - Collection of online tools
- smalldev.tools - Developer utilities
- toolur.com - Image and file tools
- browserling.com/tools - Developer tools
- emn178.github.io/online-tools - Text/encoding tools

## Metrics to Analyze

### Traffic Indicators

| Metric | Source | What It Shows |
|--------|--------|---------------|
| Alexa Rank | alexa.com (archived) | Relative popularity |
| SimilarWeb | similarweb.com | Traffic estimates |
| Reddit mentions | reddit search | Community interest |
| Backlinks | ahrefs free, moz free | SEO strength |

### Feature Comparison

Create matrix comparing:
- Number of tools/apps
- Categories covered
- Mobile responsiveness
- Ad presence (none, some, heavy)
- Load speed
- UI quality
- Localization support

### Marketing Presence

Check each competitor for:
- [ ] Product Hunt listing
- [ ] AlternativeTo listing
- [ ] Reddit presence (posts, comments)
- [ ] Hacker News mentions
- [ ] Twitter/X account
- [ ] GitHub presence
- [ ] Blog/content marketing

## Finding Traffic Sources

### Backlink Analysis

Use free tools:
- Ahrefs free backlink checker
- Moz Link Explorer (limited free)
- Ubersuggest (limited free)

Look for:
- Directory listings
- Blog mentions
- Forum links
- Social media links

### Social Mentions

Search each platform:
- Reddit: `site:reddit.com "[competitor name]"`
- Twitter: Search competitor name
- HN: `site:news.ycombinator.com "[competitor name]"`

## Identifying Gaps

After analysis, identify:

1. **Missing features** - What do competitors have that we don't?
2. **Quality gaps** - Where can we be better?
3. **Channel gaps** - Where are they that we aren't?
4. **Audience gaps** - Who are they reaching that we're not?
